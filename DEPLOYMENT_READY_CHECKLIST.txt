═══════════════════════════════════════════════════════════════════════════
                        TROUBLESHOOTING DEPLOYMENT
═══════════════════════════════════════════════════════════════════════════

ISSUE: Blank white page
SOLUTION:
  - Check logs/error.log for errors
  - Verify .env file exists and is readable
  - Check database connection settings
  - Ensure PHP version is 8.0+

ISSUE: Database connection error
SOLUTION:
  - Verify database credentials in .env
  - Check database server is running
  - Test connection: mysql -h HOST -u USER -p
  - Verify database name exists

ISSUE: Permission denied errors
SOLUTION:
  - Set directory permissions: chmod 755 directories
  - Set file permissions: chmod 644 files
  - Make logs/ writable: chmod 777 logs/
  - Make uploads/ writable: chmod 777 uploads/

ISSUE: Session errors
SOLUTION:
  - Verify Redis is accessible
  - Check REDIS_HOST and REDIS_PASSWORD in .env
  - Test Redis: redis-cli -h HOST -p PORT ping

ISSUE: 404 Not Found on pages
SOLUTION:
  - Enable mod_rewrite on Apache
  - Verify .htaccess file exists
  - Check web server configuration
  - Ensure index.php is default document
